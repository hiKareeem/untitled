# Severity Classification Guidelines

## Assessment Criteria

**Reference:** Full severity examples in `data/issue-template.md`

## HIGH Severity

**Characteristics:**
- Breaks story credibility completely
- Factual impossibility or anachronism
- Professional procedures completely wrong
- Readers will definitely notice and lose trust

**Assessment factors:**
- Credibility impact: DEVASTATING
- Reader notice likelihood: DEFINITE
- Story-criticality: Affects core believability

## MEDIUM Severity

**Characteristics:**
- Stretches believability but not impossible
- Minor technical inaccuracies
- Timeline issues that could be explained
- Some readers might notice

**Assessment factors:**
- Credibility impact: MODERATE
- Reader notice likelihood: POSSIBLE
- Story-criticality: Affects immersion but not plot

## LOW Severity

**Characteristics:**
- Minor nitpicks, polish-level issues
- Small details that don't affect credibility
- Optional corrections for perfection

**Assessment factors:**
- Credibility impact: MINIMAL
- Reader notice likelihood: UNLIKELY
- Story-criticality: Does not affect plot or immersion

## INFO Level

**Characteristics:**
- Verified accurate, no issue
- Confirms correctness of claim
- Builds confidence in story accuracy

**Purpose:**
- Celebrate what's working well
- Reinforce author's accurate research
- Build trust in verification process

## Severity Assignment Process

**For each issue, assess:**
1. **Credibility impact** — How much does this affect reader trust?
2. **Reader likelihood** — Will readers actually notice this?
3. **Story-criticality** — Is this essential to plot or just detail?

**Assign severity based on combined assessment:**
- All three factors HIGH → HIGH severity
- All three factors LOW → LOW severity
- Mixed factors → MEDIUM severity
- No issue found → INFO level
