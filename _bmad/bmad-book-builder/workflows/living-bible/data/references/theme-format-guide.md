# Theme Format Guide

## Standard Theme Entry Format

This reference shows the complete structure for theme entries in the living bible.

## Template

```markdown
### [Theme Name]

**Description:** [What this theme explores in the narrative]

**Progression:**
| Phase | Chapters | Description |
|-------|----------|-------------|
| 1/5 | [range] | [Introduction description] |
| 2/5 | [range] | [Development description] |
| 3/5 | [range] | [Crisis description] |
| 4/5 | [range] | [Resolution description] |
| 5/5 | [range] | [Conclusion description] |

**Current phase:** [X/5] ([Phase Name])

**Theme carriers:**
| Character | Thematic role | Arc |
|-----------|---------------|-----|
| [Name] | [Protagonist/Antagonist/Mirror] | [Character's thematic journey] |

**Key thematic events:**
- [Chapter/Event]: [Description of theme manifestation]
- [Chapter/Event]: [Description of theme manifestation]
- [Chapter/Event]: [Description of theme manifestation]

**Associated symbols:**
- [Symbol]: [Significance to this theme]
- [Symbol]: [Significance to this theme]

**Resonances with other themes:**
- [Other theme]: [Tension / Complementarity / Echo] — [Brief explanation]
```

## Field Definitions

### Description
A concise statement (1-2 sentences) of what the theme explores or questions in the story.

### Progression Table
Tracks the theme's journey through all five phases:
- **Phase:** 1-5 scale
- **Chapters:** Narrative range where this phase manifests
- **Description:** What happens to the theme in this phase

### Current Phase
The current phase of the theme in the story's progression.

### Theme Carriers
Characters who embody, express, or are impacted by the theme:
- **Protagonist:** Primary carrier, embodies the theme's journey
- **Antagonist:** Opposes or complicates the theme
- **Mirror:** Reflects alternative perspective on theme
- **Catalyst:** Triggers theme manifestations in others

### Key Thematic Events
Key narrative moments where the theme is explicitly present or advanced.

### Associated Symbols
Recurring symbols, objects, or motifs that represent the theme.

### Resonances with Other Themes
Connections to other themes:
- **Tension:** Themes work at cross-purposes
- **Complementarity:** Themes reinforce each other
- **Echo:** Themes resonate or reflect similar ideas

## Example: Complete Theme Entry

```markdown
### Trust vs Distrust

**Description:** The exploration of how trust is built, broken, and rebuilt in a hostile environment.

**Progression:**
| Phase | Chapters | Description |
|-------|-----------|-------------|
| 1/5 | 1-5 | Dominant mistrust, individual survival |
| 2/5 | 6-10 | First openings, need for the group |
| 3/5 | 11-15 | Trust crisis, betrayal or sacrifice |
| 4/5 | 16-20 | Rebuilding, new dynamic |
| 5/5 | 21-25 | Resolution, trust gained or lost for good |

**Current phase:** 3/5 (Crisis)

**Theme carriers:**
| Character | Thematic role | Arc |
|------------|-----------------|-----|
| Marc | Protagonist | Mistrust → Trust → Ultimate test |
| Julie | Positive mirror | Naive trust → Betrayal → Healed mistrust |
| Chen | Thematic antagonist | Pragmatic mistrust → Selective trust |

**Key thematic events:**
- Chapter 3: Marc refuses Julie's help (mistrust established)
- Chapter 8: Forced alliance against a shared threat (first opening)
- Chapter 12: Chen betrayed by his former group (crisis)

**Associated symbols:**
- The outstretched hand: Offer of trust, often rejected then accepted
- The turned back: Vulnerability of trust

**Resonances with other themes:**
- Survival vs Humanity: Tension — mistrust favors survival but erodes humanity
- Leadership: Complementarity — a leader must inspire trust
```

## New Theme Template

When introducing a new theme:

```markdown
### [New Theme Name]

**Description:** [What this theme explores]

**Initial phase:** 1/5 (Introduction)

**First manifestation:**
- Chapter/Day: [When it appeared]
- How: [How it manifested]

**Initial carriers:**
| Character | Role | Reason |
|------------|------|--------|
| [Name] | [role] | [Why they carry this theme] |

**Narrative potential:**
- Likely direction: [How this theme might evolve]
- Potential conflicts: [With other themes or characters]
```
