# Theme Phases Reference

## Phase Scale (1-5)

This reference defines the five phases of thematic progression in the living bible system.

### Phase Definitions

| Phase | Name | Description |
|-------|------|-------------|
| 1/5 | Introduction | Theme established, initial tension present |
| 2/5 | Development | Theme explored, complications arise |
| 3/5 | Crisis | Theme in maximal conflict, peak tension |
| 4/5 | Resolution | Movement toward conclusion |
| 5/5 | Conclusion | Theme resolved (positively or negatively) |

### Phase Progression Guidelines

**Critical Rules:**
- Themes must progress sequentially (no skipping phases)
- Phase progression requires evidence from the narrative
- Phase 3 (Crisis) is the turning point - themes may resolve positively or negatively after this
- Not all themes reach Phase 5 - some may remain in tension

### Phase Indicators

**Phase 1/5 - Introduction:**
- First mention or explicit setup
- Initial tension or question posed
- Character reactions establish the theme's relevance
- Symbols or motifs first appear

**Phase 2/5 - Development:**
- Theme appears in multiple contexts
- Complications or nuances emerge
- Characters take positions relative to the theme
- Tension increases but hasn't peaked

**Phase 3/5 - Crisis:**
- Theme confronts its fundamental contradiction
- Characters forced to choose or confront
- Peak emotional or narrative tension
- Clear turning point established

**Phase 4/5 - Resolution:**
- Direction of resolution clear (positive or negative)
- Characters act on their crisis choices
- New equilibrium being established
- Consequences of crisis playing out

**Phase 5/5 - Conclusion:**
- Theme reaches final state
- Character relationships to theme finalized
- Narrative consequences fully manifested
- New status quo established (or old one destroyed)

### Usage in Updates

When updating theme phases:
1. Identify current phase
2. Find evidence in narrative for progression
3. Document the trigger event
4. Update to next phase ONLY with clear evidence
5. Note whether resolution appears positive or negative
