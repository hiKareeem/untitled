# Objects

> Living Narrative Bible - Material Dimension
> Inventory of significant objects with origins, meaning, and status

---

## Usage Instructions

This bible dimension tracks **plot-critical objects**:

- **Only significant objects** are documented (not trivial items)
- **Origin** of each object is traced
- **Symbolic meaning** is noted
- **Ownership transfers** are recorded

### Significance Criteria

An object deserves documentation if it:
- [ ] Influences the plot
- [ ] Reveals something about a character
- [ ] Creates or resolves a conflict
- [ ] Has symbolic value

### Entry Format

```markdown
### [Object Name]

**Origin:**
- Provenance: [Where it comes from]
- Discovered/Created: Day [N], by [character]
- Circumstances: [How it was found/made]

**Description:**
- Appearance: [Physical description]
- Function: [What it does]
- Condition: [Current state]

**Significance:**
- Symbolism: [What it represents]
- Stakes: [Why it matters for the plot]
- Potential Conflicts: [Who wants it and why]

**Current Owner:** [Name or "Lost"/"Destroyed"]

**History:**
- Day [N]: [Event involving the object]
- Day [M]: [Following event]
```
