# Dossier Structure Template

## Template Overview

This template defines the complete structure for research dossiers in the BMAD Book Builder research workflow.

## Dossier Header

```markdown
# Research Dossier: [Topic Name]
```

## Dossier Metadata

```markdown
## Dossier Metadata
- **Created:** [Current date: YYYY-MM-DD]
- **Last Updated:** [Current date: YYYY-MM-DD]
- **Source Count:** [Total number of sources]
- **Story Relevance:** [Story connection from Step 1]
- **Reliability:** [High/Medium/Low based on aggregate source quality]
```

## Overview

Write 2-3 sentences describing:
- What the topic is
- Why it matters to the story
- Brief preview of key findings

```markdown
## Overview
[Brief description of topic and why it matters to the story]
```

## Key Facts Section

Organize into sub-categories. For each fact, include:
- Fact description
- Source citation
- Verification status (✅ or ⚠️)
- Reliability rating (High/Medium/Low)

```markdown
## Key Facts

### [Category 1]
- **Fact 1:** [Description]
  - Source: [URL or reference]
  - Verification: ✅ Verified
  - Reliability: High

- **Fact 2:** [Description]
  - Source: [URL or reference]
  - Verification: ✅ Verified
  - Reliability: High

### [Category 2]
[... same format]
```

## Technical Details Section

Include specific technical information:
- Procedures with steps
- Specifications (measurements, capacities, etc.)
- Technical terminology
- Quantitative data

```markdown
## Technical Details

[Specific technical information relevant to story]
```

## Common Misconceptions Section

List misconceptions with reality and sources:

```markdown
## Common Misconceptions

- **Misconception 1:** [What people get wrong]
  - **Reality:** [What's actually true]
  - Source: [Reference]

- **Misconception 2:** [What people get wrong]
  - **Reality:** [What's actually true]
  - Source: [Reference]
```

## Story Applications Section

Create a table linking research to story elements:

```markdown
## Story Applications

| Story Element | Chapter/Scene | How Research Applies |
|---------------|---------------|----------------------|
| [Element 1] | Ch. X, Scene Y | [Application] |
| [Element 2] | Ch. X, Scene Y | [Application] |
```

## Sources Section

List all sources with reliability ratings:

```markdown
## Sources

1. **[Source Name]** — [URL or reference] — [Reliability: High/Medium/Low]
2. **[Source Name]** — [URL or reference] — [Reliability: High/Medium/Low]
3. **[Source Name]** — [URL or reference] — [Reliability: High/Medium/Low]
```

## Images/References Section

```markdown
## Images/References

- [Description with link]
- [Description with link]
```

## Notes for Author Section

Include:
- Critical warnings
- Areas of uncertainty
- Recommendations for further research
- Reminders for writing

```markdown
## Notes for Author

**Critical Warnings:**
- [Warning 1]
- [Warning 2]

**Areas of Uncertainty:**
- [Uncertainty 1]
- [Uncertainty 2]

**Recommendations:**
- [Recommendation 1]
- [Recommendation 2]
```

## Filename Guidelines

Create a filename that is:
- Descriptive but concise
- Uses kebab-case (lowercase with hyphens)
- Uniquely identifies the topic

**Examples:**
- `emergency-medicine-1970s-france.md`
- `surgical-instruments-basic-procedures.md`
- `paris-metro-1970s-routes.md`
