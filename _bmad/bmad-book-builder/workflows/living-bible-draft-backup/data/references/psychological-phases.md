# Psychological Phases Reference

This document defines the 5-phase psychological progression system for character arcs in the living bible.

## Phase System Overview

Characters progress through 5 psychological phases during their arc development. Each phase represents a distinct stage in psychological evolution.

## Phase Definitions

| Phase | Name | Description |
|-------|-----|-------------|
| 1/5 | Establishment | Personality established, no internal conflict |
| 2/5 | Disruption | First challenge to beliefs |
| 3/5 | Turning Point | Crisis, difficult choice |
| 4/5 | Transformation | Change in progress |
| 5/5 | New Identity | Arc completed |

## Phase Details

### Phase 1/5: Establishment (Establishment)

**Characteristics:**
- Established personality baseline
- Core beliefs intact and unchallenged
- No internal conflict present
- Character operates within comfort zone

**Indicators:**
- Consistent behavior patterns
- Clear motivation aligned with beliefs
- No self-doubt or questioning

**Duration:** Typically story beginning

### Phase 2/5: Disruption (Disruption)

**Characteristics:**
- First challenge to core beliefs
- Introduction of internal conflict
- Character begins questioning assumptions
- Comfort zone threatened

**Indicators:**
- Hesitation in decision-making
- Minor contradictions between beliefs and actions
- Awareness of alternative viewpoints

**Duration:** Early to middle story

### Phase 3/5: Turning Point (Turning Point)

**Characteristics:**
- Crisis moment requiring difficult choice
- Maximum internal conflict
- Old beliefs no longer sufficient
- Must choose between old and new self

**Indicators:**
- Paralysis or impulsive action
- Visible emotional turmoil
- Confrontation with truth
- Catalyst moment

**Duration:** Middle story (pivotal moment)

### Phase 4/5: Transformation (Transformation)

**Characteristics:**
- Active change in progress
- New beliefs being integrated
- Behavioral shifts observable
- Testing new identity

**Indicators:**
- Different decision patterns
- Changed relationships dynamics
- New coping mechanisms
- Gradual confidence in new self

**Duration:** Middle to late story

### Phase 5/5: New Identity (New Identity)

**Characteristics:**
- Arc completion achieved
- New belief system solidified
- Internal conflict resolved
- Character operates from new baseline

**Indicators:**
- Consistent new behavior patterns
- Confidence in new identity
- Past self recognized but transcended
- Ready for new challenges

**Duration:** Late story to resolution

## Usage Guidelines

### Progression Rules

1. **Evidence Required**: Each phase progression must be supported by story events
2. **Organic Flow**: Phases must progress naturally, not jump abruptly
3. **Reversal Possible**: Characters can regress if events warrant
4. **Multiple Arcs**: Characters may have parallel arcs with different phases

### Tracking Format

When updating character psychological states:

```markdown
**Previous state:**
- Phase: [X/5] ([phase name])
- Emotional state: [description]
- Dominant beliefs: [beliefs]

**Change trigger:**
- Event: [what happened]
- Impact: [how it affected them]

**New state:**
- Phase: [X/5] ([phase name])
- Emotional state: [new description]
- Modified beliefs: [updated beliefs]

**Behavioral manifestation:**
- Before: [how they acted]
- Now: [how they act now]
```

### Common Arc Patterns

**Individualism → Collectivism:**
- 1/5: Self-reliant, trusts no one
- 2/5: Recognizes need for others
- 3/5: Crisis: must choose self or group
- 4/5: Learning to trust and collaborate
- 5/5: Values group success alongside individual

**Mistrust → Trust:**
- 1/5: Assumes betrayal, hyper-vigilant
- 2/5: First positive interaction creates doubt
- 3/5: Crisis: must trust or lose everything
- 4/5: Testing trust, some setbacks
- 5/5: Healthy trust with boundaries

**Certainty → Ambiguity:**
- 1/5: Black-and-white thinking
- 2/5: Gray areas appear, uncomfortable
- 3/5: Crisis: absolute rules fail
- 4/5: Embracing complexity and nuance
- 5/5: Comfortable with uncertainty
