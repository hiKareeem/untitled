# BBB Folder Structure Reference

## Standard BBB Structure

The BBB (BMAD Book Builder) platform requires a specific folder structure to function correctly. This structure separates content, outputs, and planning documents.

## Target Directory Layout

```
project/
├── bbb-output/           # BBB workflow outputs and reports
│   ├── style-profile.yaml       # Author's writing style analysis
│   ├── reviews/                 # Chapter review reports
│   └── analysis/                # Project analysis documents
│
├── story-bible/          # Narrative reference materials
│   ├── characters/              # Character YAML files
│   │   ├── {character-name}.yaml
│   │   └── ...
│   ├── themes/                  # Theme definitions and tracking
│   │   └── themes.yaml
│   ├── timeline/                # Story timeline and chronology
│   │   └── timeline.yaml
│   ├── locations/               # Optional: Location descriptions
│   └── structure.md             # Optional: Plot structure outline
│
├── chapters/             # Manuscript chapters with BBB frontmatter
│   ├── chapter-01.md
│   ├── chapter-02.md
│   └── ...
│
└── plans/                # Planning documents
    ├── chapter-plan.md           # Chapter-by-chapter outline
    └── foundation.md             # Story foundation document
```

## Folder Purposes

### bbb-output/
Stores all outputs generated by BBB workflows:
- Style profile from style-capture workflow
- Chapter reviews and feedback
- Analysis reports
- Gap reports
- Migration logs

### story-bible/
Contains all narrative reference materials:
- **characters/**: YAML-formatted character profiles with psychology, relationships, and development arcs
- **themes/**: Theme definitions, symbols, motifs, and tracking
- **timeline/**: Chronological events and story timeline
- **locations/**: Setting descriptions (optional but recommended)

### chapters/
Contains the actual manuscript content:
- Each chapter is a separate markdown file
- Files must have BBB frontmatter (chapter metadata)
- Numbered sequentially: chapter-01.md, chapter-02.md, etc.

### plans/
Contains planning and foundation documents:
- Chapter plans and outlines
- Story foundation documents
- Plot architecture

## Migration Mapping

When migrating existing projects, map common structures to BBB equivalents:

| Existing Structure | BBB Target | Conversion Notes |
|-------------------|------------|------------------|
| `chapters/` or `chapitres/` | `chapters/` | Add BBB frontmatter |
| `personnages/` or `characters/` | `story-bible/characters/*.yaml` | Convert MD → YAML |
| `themes/` or `thematiques/` | `story-bible/themes/themes.yaml` | Restructure as YAML |
| `psychology/` | `story-bible/characters/{id}/psychology.md` | Attach to characters |
| `structure/` or `architecture/` | `story-bible/structure.md` | Convert format |
| `timeline/` | `story-bible/timeline/timeline.yaml` | Create if needed |
| `notes/` | `bbb-output/analysis/` | Organize appropriately |

## Frontmatter Requirements

### Chapter Frontmatter
```yaml
---
chapterNumber: 1
chapterTitle: "Chapter Title"
createdDate: "2026-01-25"
author: "Author Name"
migrationSource: "original/path/chapter-01.md"
---
```

### Character Frontmatter
```yaml
---
name: "Character Name"
role: "Protagonist"
archetype: "The Hero"

description: |
  Character description goes here.

psychology: |
  Character psychology and motivation.

contradictions:
  - Contradiction 1
  - Contradiction 2

relationships: []
  # To be populated later

notes: |
  Additional notes about the character.
---
```

## Non-Standard Structure Handling

When existing projects use non-standard structures:

1. **Analyze content** to determine semantic purpose
2. **Map by content type** rather than folder name
3. **Split combined files** into appropriate BBB structure
4. **Consolidate scattered content** logically
5. **Preserve all content** - nothing should be lost

## Verification Checklist

After creating BBB structure, verify:

- [ ] All required folders exist (bbb-output, story-bible, chapters, plans)
- [ ] story-bible/characters/ exists (even if empty initially)
- [ ] story-bible/themes/ exists
- [ ] story-bible/timeline/ exists
- [ ] chapters/ exists with numbered files
- [ ] All chapters have BBB frontmatter
- [ ] All character files are YAML format
- [ ] Original files are preserved (HYBRID mode)
