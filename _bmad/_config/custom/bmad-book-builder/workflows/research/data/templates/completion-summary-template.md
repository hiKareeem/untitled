# Completion Summary Template

## Template Overview

This template defines the structure for presenting research dossier completion summaries to users.

## Summary Header

```markdown
## ✅ Research Dossier Complete!

**Dossier Created:** [Topic Name]
**File Location:** research/dossiers/{filename}.md
**Word Count:** [N] words
```

## What's Included Section

```markdown
### What's Included
- ✅ [N] verified facts across [N] categories
- ✅ [N] reliable sources (High: [N], Medium: [N], Low: [N])
- ✅ [N] story applications identified
- ✅ [N] common misconceptions documented
- ✅ Critical facts flagged for story accuracy
```

## Story Impact Section

```markdown
### Story Impact
This dossier supports:
- [Story element 1] - Ch. X, Scene Y
- [Story element 2] - Ch. X, Scene Y
- [Story element 3] - Ch. X, Scene Y
```

## Key Findings Section (Optional)

Include 2-3 of the most critical findings the author should know:

```markdown
### Key Findings for Your Story
1. **[Critical finding 1]** — [Why it matters]
2. **[Critical finding 2]** — [Why it matters]
3. **[Critical finding 3]** — [Why it matters]
```

## Next Steps Section

```markdown
### Next Steps
You can now:
- Reference this dossier while writing relevant chapters
- Use the research to ensure accuracy in descriptions and dialogue
- Update the dossier as your story evolves (use Edit mode)
- Create additional dossiers for other topics
```

## Quick Actions Section

```markdown
### Quick Actions
- [E]dit this dossier (add more facts, update sections)
- [C]reate another dossier
- [V]alidate this dossier
- [R]eturn to main workflow

What would you like to do next?
```

## Alternative Summary Options

### For Technical Topics

```markdown
### Technical Applications
This research supports:
- Accurate technical descriptions in [Chapters]
- Proper procedure documentation in [Scenes]
- Realistic equipment/technology references in [Context]
```

### For Historical Topics

```markdown
### Historical Accuracy
This research ensures:
- Period-appropriate details in [Chapters]
- Cultural authenticity in [Scenes]
- Avoidance of anachronisms in [Context]
```

### For Character Research

```markdown
### Character Authenticity
This research supports:
- Realistic character background/profession
- Accurate character knowledge and skills
- Believable character actions and dialogue
```

## Usage Guidelines

1. **Customize for context** — Adapt sections based on dossier type
2. **Highlight value** — Emphasize what matters most for the story
3. **Be specific** — Include exact chapter/scene references when available
4. **Keep it concise** — 3-5 key findings maximum
5. **Clear next steps** — Make actions obvious and accessible
