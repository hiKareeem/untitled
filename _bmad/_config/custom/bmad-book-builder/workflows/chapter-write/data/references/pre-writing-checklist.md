## Overview

This checklist ensures all necessary context is loaded and prepared before beginning chapter writing. It contains 22 verification points across 4 categories.

## Checklist Categories

### 1. Context Files Loaded (7 items)

- [ ] **Chapter Plan** (`chapter-plan-{chapter_number}.md`)
  - Scene breakdown and objectives
  - Chapter goals and requirements

- [ ] **Story Bible** (all 5 dimensions)
  - Characters, locations, objects, chronology, themes

- [ ] **Character Dossiers**
  - All characters appearing in this chapter
  - Current psychological states

- [ ] **Style Profile** (`style-profile.md`)
  - Author's voice characteristics
  - Quantitative metrics (TTR, sentence length, complexity)

- [ ] **Previous Chapters**
  - Continuity from chapters 1 to N-1
  - Summary data from prior chapters

- [ ] **Thematic Context**
  - Current theme states
  - Thematic arc progression

- [ ] **Rhythm Guidelines**
  - Pacing targets
  - Sentence distribution patterns

### 2. Chapter Brief Preparation (7 items)

- [ ] **Chapter goal established**
  - What this chapter achieves in the story

- [ ] **Characters present identified**
  - Who appears in this chapter

- [ ] **Setting confirmed**
  - Where this chapter takes place

- [ ] **Scene-by-scene breakdown ready**
  - Key scenes mapped from plan

- [ ] **Key conflicts planned**
  - Central tension identified

- [ ] **Thematic beats identified**
  - Which themes advance in this chapter

- [ ] **Transformation objectives set**
  - Character arcs in this chapter

### 3. Psychological Preparation (4 items)

- [ ] **Each character's psychological state noted**
  - Phase (1-5) for each character present

- [ ] **Which contradictions will be tested**
  - For each character present

- [ ] **What blind spots may be relevant**
  - For key characters

- [ ] **Arc progression tracked**
  - Where each character is in their arc

### 4. Quality Thresholds (4 items)

- [ ] **TTR target identified**
  - Target: > 0.175 (Type-Token Ratio)

- [ ] **Sentence length target**
  - Target: 20-24 words average

- [ ] **Complexity target**
  - Target: 80% complex/compound, 20% simple

- [ ] **Show vs Tell intentions**
  - Balance for this chapter type

## Verification Protocol

1. **Systematic Verification**
   - Go through each checklist item in order
   - Verify the specific content is available
   - Report any missing elements

2. **Missing Item Handling**
   - IF ANY ITEM IS MISSING: "⚠️ Missing: [item]. Please address before proceeding."
   - DO NOT proceed until all items are verified

3. **Completion Confirmation**
   - ONLY when ALL items checked: "✅ All checklist items verified!"

## Success Indicators

When the checklist is complete, all systems should be ready for chapter writing:

```
✅ Context files loaded
✅ Chapter brief prepared
✅ Psychological context mapped
✅ Quality thresholds set
```

## Common Issues to Watch For

1. **Missing previous chapter summaries** - Can lead to continuity errors
2. **Incomplete character dossiers** - Results in inconsistent character behavior
3. **No rhythm guidelines** - May cause pacing issues
4. **Unclear thematic context** - Leads to weak thematic integration
