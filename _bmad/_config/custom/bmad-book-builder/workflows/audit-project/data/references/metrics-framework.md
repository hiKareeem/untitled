# Audit Metrics and Quality Framework

## Overview

This document defines the comprehensive metrics framework used in the project audit workflow, including all scoring systems, quality dimensions, and assessment criteria.

## Health Score System

### Narrative Arc Health Score (0-100 points)

#### Story Structure Completeness (20 points)

**Assessment Criteria:**
- **Excellence (18-20)**: All narrative phases present and well-executed
- **Good (15-17)**: Most phases present with minor gaps
- **Fair (12-14)**: Basic structure present with notable gaps
- **Poor (8-11)**: Significant structural weaknesses
- **Critical (0-7)**: Major structural failures

**Evaluation Points:**
- Presence of all six narrative phases (setup, inciting incident, rising action, climax, falling action, resolution)
- Clear progression between phases
- Appropriate pacing through each phase
- Effective transitions between phases

#### Arc Completion (20 points)

**Assessment Criteria:**
- **Excellence (18-20)**: Complete story arc with all elements resolved
- **Good (15-17)**: Arc largely complete with minor loose ends
- **Fair (12-14)**: Arc partially complete with significant gaps
- **Poor (8-11)**: Incomplete arc with major unresolved elements
- **Critical (0-7)**: Arc severely incomplete or broken

**Evaluation Points:**
- Character arcs reach logical conclusions
- Plot threads are resolved
- Setup/payoff relationships are satisfied
- Thematic elements are resolved
- Ending provides closure

#### Pacing Quality (20 points)

**Assessment Criteria:**
- **Excellence (18-20)**: Consistently appropriate pacing with excellent rhythm
- **Good (15-17)**: Generally good pacing with minor issues
- **Fair (12-14)**: Pacing issues notable but not story-breaking
- **Poor (8-11)**: Significant pacing problems affecting readability
- **Critical (0-7)**: Pacing severely damages story experience

**Evaluation Points:**
- Scene pacing matches content (tension = faster pace, reflection = slower)
- No rushed sequences
- No dragging sections
- Smooth pacing transitions between scenes
- Overall rhythm supports story tone

#### Character Arc Progression (15 points)

**Assessment Criteria:**
- **Excellence (13-15)**: All major characters have complete, satisfying arcs
- **Good (11-12)**: Most characters have solid arcs
- **Fair (9-10)**: Some characters have weak or incomplete arcs
- **Poor (6-8)**: Many characters lack proper arc development
- **Critical (0-5)**: Character arc development severely lacking

**Evaluation Points:**
- Clear character growth/change
- Arc motivation established
- Arc progression follows logical path
- Arc resolution satisfying
- Secondary characters also developed appropriately

#### Setup/Payoff Validity (15 points)

**Assessment Criteria:**
- **Excellence (13-15)**: All setups have satisfying payoffs, all payoffs earned
- **Good (11-12)**: Most setups/payoffs handled well
- **Fair (9-10)**: Notable setup/payoff issues
- **Poor (6-8)**: Many orphaned setups or unearned payoffs
- **Critical (0-5)**: Setup/payoff structure severely broken

**Evaluation Points:**
- Setups are identifiable
- Payoffs match setup promises
- No significant orphaned setups
- No unearned payoffs
- Setup/payoff timing appropriate

#### Transition Quality (10 points)

**Assessment Criteria:**
- **Excellence (9-10)**: All transitions smooth and clear
- **Good (7-8)**: Most transitions effective
- **Fair (5-6)**: Some confusing or jarring transitions
- **Poor (3-4)**: Many problematic transitions
- **Critical (0-2)**: Transitions severely damage coherence

**Evaluation Points:**
- Chapter-to-chapter transitions clear
- Scene transitions within chapters smooth
- Time/location changes clearly marked
- No confusing jumps
- Transitions maintain reader engagement

### Coherence Health Score (0-100 points)

#### Character Consistency (30 points)

**Assessment Criteria:**
- **Excellence (27-30)**: All characters completely consistent
- **Good (22-26)**: Minor character inconsistencies
- **Fair (17-21)**: Notable character consistency issues
- **Poor (12-16)**: Significant character inconsistencies
- **Critical (0-11)**: Character consistency severely broken

**Evaluation Points:**
- Voice consistency (dialogue patterns, speech style)
- Behavior consistency (personality, reactions, decisions)
- Physical description consistency
- Knowledge/memory continuity
- Relationship consistency
- Alignment with Living Bible (if exists)

#### Location Accuracy (20 points)

**Assessment Criteria:**
- **Excellence (18-20)**: All locations completely consistent and accurate
- **Good (15-17)**: Minor location inconsistencies
- **Fair (12-14)**: Notable location accuracy issues
- **Poor (8-11)**: Significant location inconsistencies
- **Critical (0-7)**: Location accuracy severely broken

**Evaluation Points:**
- Description consistency (layout, features, atmosphere)
- Geographic consistency (distances, directions)
- Spatial movement accuracy
- Travel time realism
- Alignment with Living Bible (if exists)

#### Object Tracking (15 points)

**Assessment Criteria:**
- **Excellence (13-15)**: All objects tracked perfectly
- **Good (11-12)**: Minor object tracking issues
- **Fair (9-10)**: Notable object presence/state inconsistencies
- **Poor (6-8)**: Significant object tracking problems
- **Critical (0-5)**: Object tracking severely broken

**Evaluation Points:**
- Presence continuity (objects exist when they should)
- State change logic
- No objects appearing/disappearing without explanation
- Special/magical object rule consistency
- Alignment with Living Bible (if exists)

#### Timeline Validation (20 points)

**Assessment Criteria:**
- **Excellence (18-20)**: Timeline completely consistent
- **Good (15-17)**: Minor timeline inconsistencies
- **Fair (12-14)**: Notable timeline issues
- **Poor (8-11)**: Significant timeline problems
- **Critical (0-7)**: Timeline severely broken

**Evaluation Points:**
- Event sequence logic
- Duration consistency
- Time gap accuracy
- Flashback/flashforward clarity
- Alignment with Living Bible (if exists)

#### Plot Hole Absence (15 points)

**Assessment Criteria:**
- **Excellence (13-15)**: No plot holes or narrative gaps
- **Good (11-12)**: Minor plot gaps
- **Fair (9-10)**: Notable plot holes
- **Poor (6-8)**: Significant plot holes
- **Critical (0-5)**: Plot holes severely damage story

**Evaluation Points:**
- No missing critical information
- All plot threads resolved
- No logic contradictions
- No cause/effect violations
- No unanswered questions raised by narrative

### Quality Health Score (0-100 points)

#### Style Consistency (20 points)

**Assessment Criteria:**
- **Excellence (18-20)**: Completely consistent style and voice
- **Good (15-17)**: Minor style inconsistencies
- **Fair (12-14)**: Notable style inconsistencies
- **Poor (8-11)**: Significant style problems
- **Critical (0-7)**: Style severely inconsistent

**Evaluation Points:**
- Narrative voice consistency
- Tone consistency
- Style register consistency
- Appropriate voice/tone shifts (intentional)
- No jarring style changes

#### Dialogue Quality (25 points)

**Assessment Criteria:**
- **Excellence (22-25)**: Excellent dialogue throughout
- **Good (18-21)**: Good dialogue with minor issues
- **Fair (14-17)**: Notable dialogue problems
- **Poor (10-13)**: Significant dialogue issues
- **Critical (0-9)**: Dialogue severely weak

**Evaluation Points:**
- Character voice distinctiveness (10 points)
- Dialogue naturalness (7 points)
- Subtext and depth (5 points)
- Dialogue mechanics (3 points)

**Voice Distinctiveness Scoring:**
- All major characters have unique voices: 9-10
- Most characters unique: 7-8
- Some voice blending: 5-6
- Significant voice blending: 3-4
- Little voice distinction: 0-2

#### Prose Metrics (25 points)

**Assessment Criteria:**
- **Excellence (22-25)**: Excellent prose quality throughout
- **Good (18-21)**: Good prose with minor issues
- **Fair (14-17)**: Notable prose problems
- **Poor (10-13)**: Significant prose issues
- **Critical (0-9)**: Prose severely weak

**Evaluation Points:**
- Vocabulary variety (6 points)
- Sentence structure variety (6 points)
- Readability (7 points)
- Show vs tell balance (6 points)

**Vocabulary Variety Scoring:**
- Wide variety, no repetition: 6
- Good variety, minimal repetition: 5
- Adequate variety, some repetition: 3-4
- Limited variety, notable repetition: 1-2
- Severe repetition issues: 0

**Readability Scoring:**
- Excellent readability: 7
- Good readability: 5-6
- Fair readability: 3-4
- Poor readability: 1-2
- Severe readability issues: 0

#### Thematic Coherence (20 points)

**Assessment Criteria:**
- **Excellence (18-20)**: Strong thematic development
- **Good (15-17)**: Good thematic coherence
- **Fair (12-14)**: Notable thematic weaknesses
- **Poor (8-11)**: Significant thematic problems
- **Critical (0-7)**: Thematic coherence severely lacking

**Evaluation Points:**
- Theme presence across manuscript
- Theme development and progression
- Thematic consistency with events
- Symbol/motif effectiveness
- Alignment with Living Bible (if exists)

#### Quality Pattern Strength (10 points)

**Assessment Criteria:**
- **Excellence (9-10)**: Consistent strengths throughout
- **Good (7-8)**: Notable strengths maintained
- **Fair (5-6)**: Some strengths, some weaknesses
- **Poor (3-4)**: Weak patterns dominate
- **Critical (0-2)**: No consistent strengths

**Evaluation Points:**
- Recurring strengths identified
- Effective techniques used repeatedly
- Quality trajectory improving/stable
- Learning from previous work visible

## Historical Progress Score (0-100 points)

### Quality Trend Assessment

**Improvement Trend (70-100 points):**
- Significant improvement: 90-100
- Moderate improvement: 80-89
- Slight improvement: 70-79

**Stable Trend (50-69 points):**
- Consistent quality: 60-69
- Minor fluctuations: 50-59

**Decline Trend (0-49 points):**
- Slight decline: 30-49
- Moderate decline: 10-29
- Significant decline: 0-9

### Issue Resolution Tracking

**Resolution Success Impact:**
- Most previous issues resolved: +20 points
- Some previous issues resolved: +10 points
- Few previous issues resolved: 0 points
- Previous issues persist: -10 points

**New Issues Impact:**
- Few/minor new issues: +5 points
- Moderate new issues: 0 points
- Many/major new issues: -10 points

## Overall Project Health Calculation

### Weighted Formula

```
Overall Health Score =
  (Narrative Arc Score × 0.25) +
  (Coherence Score × 0.30) +
  (Quality Score × 0.25) +
  (Historical Progress Score × 0.10) +
  (Data Currency Score × 0.10)
```

### Assessment Labels

**Excellent (90-100):**
- Project in outstanding health
- Ready for final polish
- Only minor issues remaining

**Good (75-89):**
- Solid project health
- Minor improvements needed
- On track for success

**Fair (60-74):**

**Poor (40-59):**
- Significant health problems
- Substantial work required
- Major revision needed

**Critical (0-39):**
- Major health failures
- Comprehensive revision needed
- Fundamental issues to address

## Issue Severity Framework

### Critical Issues

**Definition:**
- Must fix before finalizing
- Break narrative logic or credibility
- Confuse readers significantly
- Undermine story structure

**Examples:**
- Plot holes that break story logic
- Major character inconsistencies
- Timeline violations that confuse events
- Broken narrative arc
- Unresolved major plot threads
- Severe coherence failures

### Major Issues

**Definition:**
- Should fix before publishing
- Noticeable problems affecting reading experience
- Inconsistencies that distract
- Gaps in development

**Examples:**
- Minor character inconsistencies
- Location description conflicts
- Some setup/payoff problems
- Dialogue voice blending
- Pacing issues in sections
- Thematic inconsistencies

### Minor Issues

**Definition:**
- Polish before final
- Small inconsistencies or weaknesses
- Stylistic improvements
- Editorial refinements

**Examples:**
- Word repetition
- Minor prose tweaks
- Small style inconsistencies
- Occasional pacing adjustments
- Minor dialogue improvements
- Small thematic clarifications

## Quality Patterns Recognition

### Systemic Issue Patterns

**Cross-Dimension Issues:**
- Character voice problems (coherence + quality + character audits)
- Pacing problems (narrative arc + rhythm tracking)
- Theme development (quality + theme tracking)
- Dialogue naturalness (quality + character consistency)

**Recurring Problem Types:**
- Consistency lapses across multiple elements
- Structural weaknesses appearing in multiple forms
- Quality issues affecting multiple dimensions

### Strength Patterns

**Consistent Strengths:**
- Elements author executes well repeatedly
- Techniques that work across manuscript
- Skills that show professional quality

**Strength Maintenance:**
- Preserve what's working
- Build on existing strengths
- Apply successful techniques to weak areas

## Assessment Best Practices

### Scoring Principles

1. **Be Specific**: Base scores on specific examples, not general impressions
2. **Be Consistent**: Apply criteria uniformly across all assessments
3. **Be Fair**: Acknowledge both strengths and weaknesses
4. **Be Constructive**: Scores should guide improvement
5. **Be Honest**: Don't inflate scores to avoid criticism

### Context Considerations

**Project Phase:**
- Early draft: Lower scores acceptable, focus on structure
- Mid draft: Moderate scores expected, focus on development
- Late draft: Higher scores required, focus on polish

**Genre Expectations:**
- Different genres have different priorities
- Adjust criteria emphasis based on genre
- Acknowledge genre-specific strengths

**Author Experience:**
- New authors: More developmental issues expected
- Experienced authors: Higher quality standards
- Professional authors: Near-perfect execution expected

### Progress Tracking

**Comparative Analysis:**
- Compare current scores to previous audits
- Note improvement or decline trends
- Track issue resolution over time

**Goal Setting:**
- Set realistic improvement targets
- Prioritize critical issues first
- Build on existing strengths
