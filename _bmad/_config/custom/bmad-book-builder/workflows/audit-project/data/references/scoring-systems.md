# Audit Scoring Systems

## Overview

This document provides the complete scoring system definitions used in the project audit workflow. All scores are calculated on a 0-100 scale with specific assessment criteria for each dimension.

## Scoring Principles

### General Guidelines

1. **Evidence-Based Scoring**: All scores must be based on specific examples from the manuscript
2. **Consistent Application**: Apply criteria uniformly across all assessments
3. **Holistic Evaluation**: Consider the manuscript as a complete work, not isolated parts
4. **Context-Aware**: Adjust expectations based on project phase, genre, and author experience
5. **Improvement-Focused**: Scores should guide revision and improvement

### Score Ranges

**Excellent (90-100)**: Professional-quality work with minimal issues
**Good (75-89)**: Solid work with minor improvements needed
**Fair (60-74)**: Functional work with notable issues
**Poor (40-59)**: Significant problems requiring substantial work
**Critical (0-39)**: Major failures requiring comprehensive revision

## Overall Project Health Calculation

### Weighted Formula

```
Overall Health Score =
  (Narrative Arc Score × 0.25) +
  (Coherence Score × 0.30) +
  (Quality Score × 0.25) +
  (Historical Progress Score × 0.10) +
  (Data Currency Score × 0.10)
```
