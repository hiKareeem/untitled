# Issue Identification Procedures for Step 5

## Issue Compilation Process

### Source Collection

**Collect issues from:**
- **Step 3 (Reference Check):** Claims contradicted by research dossiers
- **Step 4 (Web Verification):** Claims contradicted by web sources

**For each issue, use the issue template from:** `data/issue-template.md`

**Brief issue structure:**
- issue_id, source_claim, category, subcategory, location
- problem, evidence, severity (HIGH/MEDIUM/LOW)
- corrections (option_1, option_2, option_3), impact

## Issue Organization Strategy

### Severity-Based Sorting

**Sort issues in this order:**
1. HIGH severity first
2. MEDIUM severity second
3. LOW severity third

### Within Each Severity Level

**Group by category:**
- Technical (procedures, tools, knowledge, timeline)
- Factual (geographic, historical, scientific details)
- Logical (cause-effect, character behavior, plot consistency)

**Within each category:**
- Sort by chapter/scene order for easy navigation

## Verified Facts Summary

### Compilation Process

**Collect verified claims:**
- Verified via dossiers (Step 3)
- Verified via web (Step 4)

**Organize by category:**
- Technical verified facts
- Factual verified facts
- Logical verified facts

**Include in summary:**
- Claim text
- Verification source
- Confidence level
- Story applications
