# Correction Development Guidelines

## Reference

**Full correction examples and templates:** `data/issue-template.md`

## Core Principles

### Specificity
- Be concrete and actionable
- Provide exact wording or structural changes
- Include context for where corrections apply

### Multiple Options
- Offer 2-3 specific correction options when possible
- Each option should address the problem differently
- Let author choose based on story needs

### Story Respect
- Honor established story context and character
- Maintain narrative voice and tone
- Preserve author's creative vision

### Minimal Disruption
- Prioritize corrections with smallest narrative changes
- Consider ripple effects on plot/character
- Avoid creating new inconsistencies

### Style Consistency
- Match story's existing writing style
- Maintain character voice and dialogue patterns
- Preserve scene pacing and atmosphere

## Correction Option Structure

**For each issue, prepare 2-3 options:**

**Option 1:** Minimal change approach
- Quick fix with smallest narrative adjustment
- Best for: Tight deadlines, minor issues

**Option 2:** Moderate revision approach
- More substantial change but preserves core scene
- Best for: Most situations, balance of quality/effort

**Option 3:** Comprehensive rewrite approach
- Full scene rework if needed
- Best for: HIGH severity issues, story-critical problems

## Impact Assessment

**For each correction, specify:**
- **Scope:** What needs to change (single line, paragraph, scene)
- **Effort:** Approximate revision time (quick, moderate, extensive)
- **Ripple effects:** Other scenes/chapters affected
- **Trade-offs:** What might be lost/gained with this fix

## Quality Checklist

**Before presenting corrections, verify:**
- [ ] Each option directly addresses the identified problem
- [ ] Corrections are factually/technically accurate
- [ ] Options respect story context and character
- [ ] Wording matches story style and voice
- [ ] Impact on other scenes is considered
- [ ] Author has real choice between options (not just variations of same fix)
