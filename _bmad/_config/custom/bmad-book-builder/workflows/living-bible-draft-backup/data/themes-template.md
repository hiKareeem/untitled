# Themes

> Living Narrative Bible - Semantic Dimension
> Thematic progression and character-theme connections

---

## Usage Instructions

This bible dimension tracks **theme evolution**:

- **Progression**: how each theme evolves per chapter
- **Carriers**: which characters embody each theme
- **Manifestations**: dialogue, action, symbol
- **Resonances**: connections between themes

### Thematic Phases

| Phase | Name | Description |
|-------|------|-------------|
| 1/5 | Introduction | Theme established, initial tension |
| 2/5 | Development | Theme explored, complications |
| 3/5 | Crisis | Theme at maximum conflict |
| 4/5 | Resolution | Movement toward conclusion |
| 5/5 | Conclusion | Theme resolved (+ or -) |

### Entry Format

```markdown
### [Theme Name]

**Description:** [What this theme explores]

**Progression:**
| Phase | Chapters | Description |
|-------|----------|-------------|
| 1/5 | [N-M] | [Description of this phase] |
| 2/5 | [N-M] | [Description] |
...

**Current Phase:** [X/5] ([Phase Name])

**Theme Carriers:**
| Character | Thematic Role | Arc |
|-----------|----------------|-----|
| [Name] | [Protagonist/Antagonist/Mirror] | [Description] |

**Key Thematic Events:**
- Chapter [N]: [How theme manifested]
- Chapter [M]: [Following event]

**Associated Symbols:**
- [Object/Image]: [Meaning]

**Resonances with Other Themes:**
- [Other theme]: [Connection/Tension]
```
