# Structure Generation Guide

## Overview

This document provides templates and guidelines for generating phase-based story structures. Use this when creating the story architecture in step 5.

---

## Phase Structure Template

For each major story section, create a PHASE with this format:

```markdown
### PHASE [N]: [Phase Name]

**Durée estimée:** [X] chapitres

**Objectifs narratifs:**
- [What this phase accomplishes narratively]
- [What reader should understand/feel]

**Beats du framework ([Framework Name]):**
- [Beat 1]: [How it manifests in this story]
- [Beat 2]: [How it manifests in this story]

**Conflits principaux:**
- [Main conflict(s) in this phase]

**Évolution du personnage:**
- [Protagonist]: [Where they are in their arc]
- [Other key characters]: [Their state/development]

**Scènes clés suggérées:**
1. [Key scene description]
2. [Key scene description]
3. [Key scene description]

**Fin de phase / Déclencheur:**
[What ends this phase and triggers the next]

---
```

## Framework-to-Phase Mapping

### Save the Cat → 4-5 Phases

**Phase 1: Setup (Act I)**
- Beats: Opening Image, Theme Stated, Setup, Catalyst, Debate
- Duration: ~3-4 chapters
- Purpose: Establish status quo, introduce protagonist, trigger event

**Phase 2: Fun & Games (Act IIa)**
- Beats: Break into Two, B Story, Fun and Games, Midpoint
- Duration: ~5-7 chapters
- Purpose: Protagonist navigates new world, false victory at midpoint

**Phase 3: Bad Guys Close In (Act IIb)**
- Beats: Bad Guys Close In, All Is Lost, Dark Night of the Soul
- Duration: ~4-6 chapters
- Purpose: Things fall apart, darkest moment, soul-searching

**Phase 4: Finale (Act III)**
- Beats: Break into Three, Finale, Final Image
- Duration: ~3-4 chapters
- Purpose: Solution found, final confrontation, transformation complete

### Hero's Journey → 3 Phases

**Phase 1: Departure**
- Stages: Ordinary World, Call to Adventure, Refusal, Mentor, Threshold
- Duration: ~4-5 chapters
- Purpose: Hero receives call, crosses threshold into special world

**Phase 2: Initiation**
- Stages: Tests, Approach, Ordeal, Reward
- Duration: ~7-10 chapters
- Purpose: Hero faces trials, major ordeal, seizes reward

**Phase 3: Return**
- Stages: Road Back, Resurrection, Return with Elixir
- Duration: ~4-5 chapters
- Purpose: Hero returns transformed, faces final test, brings gift

### Marie Vareille → Variable Phases

**Phase 1: Setup**
- Element: Setup before trigger
- Duration: ~2-3 chapters
- Purpose: Establish protagonist and world

**Phase 2: Trigger & Conflits**
- Element: Élément déclencheur, rising conflicts
- Duration: ~4-6 chapters
- Purpose: Action begins, conflicts escalate

**Phase 3: Actions & Climax**
- Element: Actions leading to climax
- Duration: ~4-5 chapters
- Purpose: Confrontation, highest stakes

**Phase 4: Résolution**
- Element: Aftermath
- Duration: ~1-2 chapters
- Purpose: Consequences, new status quo

### Snowflake Method → Based on Synopsis Structure

Phases determined by the 4-page synopsis structure. Typically:
- Phase 1: Setup (from synopsis paragraph 1)
- Phase 2: Major disasters (paragraph 2)
- Phase 3: Resolution (paragraph 3)

### Custom Framework → As Defined

Phases match the custom structure defined by the author.

## Verification Checklist

```markdown
## Checklist de Vérification

### Structure
- [ ] Toutes les phases ont des objectifs clairs
- [ ] Les transitions entre phases sont logiques
- [ ] Le rythme varie (tension/respiration)
- [ ] L'escalade des enjeux est présente
- [ ] Chaque phase gagne sa place (rien de superflu)

### Personnages
- [ ] L'arc du protagoniste est visible à travers les phases
- [ ] L'antagoniste/opposition est présent(e) de manière cohérente
- [ ] Les personnages secondaires ont des rôles définis
- [ ] Les évolutions des personnages sont tracées

### Framework
- [ ] Tous les beats/étapes du framework sont couverts
- [ ] Le mapping framework → phases est cohérent
- [ ] Les proportions recommandées sont respectées
- [ ] Le rythme du framework est respecté

### Cohérence
- [ ] Les fils narratifs sont trackés à travers les phases
- [ ] Les thèmes sont tissés dans la structure
- [ ] Le ton est cohérent ou évolue intentionnellement
- [ ] Les enjeux augmentent de manière logique

### Complétude
- [ ] Toutes les phases ont des scènes clés suggérées
- [ ] Chaque phase a un déclencheur clair vers la suivante
- [ ] L'histoire a un début, milieu, fin distincts
- [ ] La transformation du protagoniste est tracée
```

## Generation Principles

### Apply Framework Systematically

1. **Load framework data** — Understand the complete framework
2. **Map beats to phases** — Group framework elements into logical phases
3. **Connect to story elements** — Use discovered characters, world, themes
4. **Ensure integrity** — Every phase must earn its place

### Ensure Structural Integrity

**Each phase MUST have:**
- Clear narrative purpose
- Connection to framework beats
- Character evolution/development
- Key scenes suggested
- Clear transition to next phase

**Common pitfalls to avoid:**
- Generic phases not tied to story specifics
- Missing framework beats
- Vague transitions
- No character evolution in phase
- Phases that feel "padded"

### Use All Gathered Inputs

**Synthesize from:**
- **Step 2 (Concept):** Genre, tone, audience, format
- **Step 3 (Framework):** Selected framework and principles
- **Step 4 (Discovery):** Characters, world, themes, beats

**Don't generate in isolation** — The structure must emerge from the author's specific story elements.

## Phase Naming Guidelines

### Phase Names Should Be:
- **Descriptive** — Indicate what happens in the phase
- **Evocative** — Suggest the emotional tone
- **Varied** — Don't repeat names or patterns

### Examples:
- ✅ "Phase 1: The Call" (evocative, clear)
- ✅ "Phase 2: Into the Unknown" (descriptive, intriguing)
- ✅ "Phase 3: The Darkest Hour" (emotional, clear)
- ❌ "Phase 1: Setup" (too generic)
- ❌ "Phase 2: More Stuff Happens" (not descriptive)

## Scene Suggestions Guidelines

### Key Scenes Should:
- **Advance the plot** — Move story forward
- **Reveal character** — Show who they are
- **Escalate stakes** — Raise tension/conflict
- **Connect to themes** — Explore thematic questions
- **Vary the rhythm** — Mix action, dialogue, introspection

### Number of Scenes per Phase:
- **Short phase (2-3 chapters):** 3-5 key scenes
- **Medium phase (4-6 chapters):** 5-8 key scenes
- **Long phase (7+ chapters):** 8-12 key scenes

### Scene Variety:
Ensure mix of:
- Action scenes (external conflict)
- Dialogue scenes (character interaction)
- Introspection scenes (internal processing)
- Revelation scenes (discoveries, twists)

## Common Structure Issues to Avoid

### Issue: Phases Feel Disconnected

**Solution:**
- Clear trigger ending each phase
- Explicit transition to next phase
- Narrative threads spanning multiple phases

### Issue: Pacing is Flat

**Solution:**
- Vary tension within phases
- Ensure escalation overall
- Include breathing room between high-tension moments

### Issue: Character Arc Unclear

**Solution:**
- Explicitly track character state per phase
- Show evolution in every phase
- Connect arc to framework beats

### Issue: Framework Not Applied

**Solution:**
- Map every framework beat to a phase
- Explicitly note which beats occur where
- Respect framework proportions
