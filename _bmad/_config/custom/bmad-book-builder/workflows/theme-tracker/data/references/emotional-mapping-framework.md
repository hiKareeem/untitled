# Emotional Mapping Framework

Reference guide for tracking character emotional beats throughout chapters.

## Overview

Emotional mapping documents observable emotional states, triggers, expressions, and impacts for each character throughout a chapter. This is OBSERVATIONAL work - map what's shown, not what's assumed.

## Core Principles

### 1. Observable Evidence Only

**Valid emotional indicators:**
- Direct descriptions ("she felt angry")
- Physical cues (clenched fists, tears, laughter)
- Dialogue tone and content
- Actions revealing emotional state
- Reactions to events/characters

**Invalid indicators:**
- Assumptions about internal states
- Interpretations without evidence
- Generalizations without specifics
- Feelings not demonstrated in text

### 2. Beat Structure

Each emotional beat must include:

**Emotional State:**
- Specific emotion (angry, joyful, fearful, etc.)
- Intensity level if relevant (mild, moderate, intense)

**Trigger:**
- What caused the emotion
- Event, dialogue, or realization
- Must be textually identifiable

**Expression:**
- How the emotion is shown
- Dialogue, action, physical manifestation
- Must be directly observable

**Impact on Others:**
- How other characters react
- Effect on scene dynamics
- Consequences for relationships

### 3. Trajectory Mapping

For characters with multiple beats, map the emotional journey:

**Format:**
[Starting State] → [Key Shift] → [Ending State]

**Example:**
Méfiance → Surprise → Gratitude hésitante

## Identification Protocol

### Step 1: Character Presence

Identify all characters with significant presence:

**Include:**
- POV characters
- Speaking roles
- Characters with meaningful actions
- Characters whose emotional state affects scene

**Exclude:**
- Background characters
- Nameless crowd members
- Characters with purely functional presence

### Step 2: Emotional Moment Scanning

For each significant character, scan chapter for:

**Direct Descriptions:**
- "she felt..."
- "he was overcome with..."
- "anger filled her..."

**Physical Indicators:**
- Facial expressions
- Body language
- Physical reactions
- Voice changes

**Dialogue Content:**
- Tone and word choice
- What is said (and not said)
- Emotional subtext
- Questions asked

**Actions:**
- Choices made
- Reactions to events
- Interactions with others
- Avoidance behaviors

**Reactions:**
- Responses to other characters
- Emotional contagion
- Defensiveness or openness

### Step 3: Beat Documentation

For each emotional moment found:

```markdown
**Beat N:**
- **État émotionnel:** [Specific emotion]
- **Déclencheur:** [What triggered it]
- **Expression:** [How shown - dialogue/action/physical]
- **Impact sur les autres:** [Effect on other characters]
```

### Step 4: Trajectory Analysis

For characters with multiple beats:

**Identify:**
- Starting emotional state
- Shift points (where emotion changes)
- Ending emotional state
- Pattern or progression

**Document:**
- [Character]: [Start] → [Shift] → [End]

### Step 5: Interaction Mapping

Note moments where emotions interact:

**Types of interactions:**
- Emotional contagion (one character's emotion triggers another's)
- Emotional opposition (conflicting emotions)
- Emotional amplification (emotions intensify each other)
- Emotional regulation (one character modulates another's)

**Format:**
[Character A]'s [emotion] triggers [Character B]'s [response]

## Emotional State Categories

### Primary Emotions

**Basic emotions to look for:**
- Joy/happiness
- Sadness/grief
- Anger/rage
- Fear/anxiety
- Surprise/shock
- Disgust/revulsion

### Complex Emotional States

**Nuanced emotions:**
- Bittersweet (joy + sadness)
- Wistful (desire + resignation)
- Resentful (anger + helplessness)
- Conflicted (opposing emotions)
- Guarded (fear + defensiveness)

### Emotional Absence

**Note when characters show:**
- Flat affect (no emotional response)
- Emotional masking (hiding true feelings)
- Dissociation (emotional detachment)
- Suppression (conscious control of emotion)

**This can be:**
- Intentional (character choice)
- Potential issue (lack of emotional depth)
- Thematic (character trait)

## Common Patterns

### Single-Beat Characters

**Character appears with one dominant emotion:**
- Document the single beat
- Note why this is sufficient
- Consider if this is intentional or limiting

### Multi-Beat Trajectories

**Character shows emotional progression:**
- Map the full trajectory
- Identify turning points
- Note pattern significance

### Emotional Static

**Character shows no change:**
- Document absence of beats
- Consider if this is intentional
- Flag as potential issue if concerning

## Continuity Checking

### Chapter-to-Chapter Continuity

**Verify:**
- Where did character end emotionally last chapter?
- Does this chapter's opening align?
- Are there unexplained emotional shifts?

**Address:**
- If aligned: Note continuity
- If misaligned: Flag as potential issue
- If unexplained: Note in red flags

## Evidence Quality Checklist

For each emotional beat:

- [ ] Emotion is textually supported
- [ ] Trigger is clearly identifiable
- [ ] Expression is observable
- [ ] Impact on others is noted
- [ ] Not assuming internal state
- [ ] Not over-interpreting
- [ ] Specific, not general
- [ ] Documentation complete

## Common Pitfalls

### Over-Mapping

**Claiming emotions when:**
- Text doesn't support the claim
- Interpreting instead of observing
- Assuming emotional states without evidence

**Avoid by:**
- Sticking to observable indicators
- Requiring textual support
- Not filling in gaps

### Under-Mapping

**Missing emotions when:**
- Subtle indicators present
- Physical cues overlooked
- Subtext not recognized

**Avoid by:**
- Looking for non-verbal indicators
- Considering subtext
- Checking for physical cues

### Misattribution

**Wrong character or wrong emotion:**
- Confusing cause and effect
- Misinterpreting reactions
- Missing emotional complexity

**Avoid by:**
- Careful textual reading
- Considering context
- Acknowledging complexity

## Examples

### Example 1: Complete Beat Documentation

**Character:** Sarah

**Beat 1:**
- **État émotionnel:** Controlled anxiety
- **Déclencheur:** Anniversary of mother's death
- **Expression:** Over-organizes supplies, checks inventory three times
- **Impact sur les autres:** Team feels managed, not led; discomfort

**Beat 2:**
- **État émotionnel:** Defensive anger
- **Déclencheur:** Marc questions her organizational decisions
- **Expression:** Voice sharp, shuts down discussion abruptly
- **Impact sur les autres:** Marc withdraws; Julie uncomfortable

**Beat 3:**
- **État émotionnel:** Vulnerable sadness
- **Déclencheur:** Finding old photo of mother
- **Expression:** Voice catches, turns away quickly
- **Impact sur les autres:** Chen notices, pretends not to see

**Trajectory:** Controlled anxiety → Defensive anger → Vulnerable sadness

### Example 2: Interaction Mapping

**Interaction:** Marc's suspicion triggers Julie's defensiveness

**Breakdown:**
- Marc: Emotional state = Suspicious
- Expression: Questions Julie's story too closely
- Julie: Triggered emotion = Defensive
- Expression: Changes subject, avoids eye contact
- Dynamic: Escalating mistrust cycle

### Example 3: Emotional Static Flag

**Character:** Chen

**Observation:** Present throughout chapter, no emotional beats detected

**Assessment:**
- Character has speaking role
- No emotional indicators in dialogue
- No physical cues described
- Actions purely functional

**Flag:** ⚠️ Personnage sans beats émotionnels - présent mais émotionnellement neutre
