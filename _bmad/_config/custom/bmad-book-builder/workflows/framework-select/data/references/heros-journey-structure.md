# Hero's Journey: Complete Framework Structure

## Framework Overview

**Name:** Hero's Journey (Monomyth)
**Type:** Stage-based journey
**Total Stages:** 12
**Phases:** 3 (Departure, Initiation, Return)
**Origin:** Joseph Campbell

## Complete Stage Structure

### Phase 1: Departure (Stages 1-5)

#### 1. Ordinary World
- **Purpose:** Show protagonist's normal life
- **Chapter Target:** 1
- **Key Elements:** Establish baseline, show what's missing

#### 2. Call to Adventure
- **Purpose:** Inciting incident, challenge appears
- **Chapter Target:** 1-2
- **Key Elements:** Problem or opportunity presented

#### 3. Refusal of the Call
- **Purpose:** Initial hesitation or fear
- **Chapter Target:** 2-3
- **Key Elements:** Resistance, doubts, fears expressed

#### 4. Meeting the Mentor
- **Purpose:** Guide provides advice/tools
- **Chapter Target:** 3-4
- **Key Elements:** Mentor appears, provides guidance or items

#### 5. Crossing the Threshold
- **Purpose:** Leave ordinary world, enter special world
- **Chapter Target:** 4-5
- **Key Elements:** Point of no return, enter unknown

### Phase 2: Initiation (Stages 6-9)

#### 6. Tests, Allies, Enemies
- **Purpose:** Learn rules, make friends, face foes
- **Chapter Target:** 5-10
- **Key Elements:** Explore special world, establish alliances

#### 7. Approach to Inmost Cave
- **Purpose:** Plan for the major challenge
- **Chapter Target:** 10-12
- **Key Elements:** Prepare for central confrontation

#### 8. Ordeal
- **Purpose:** Major confrontation, near-death experience
- **Chapter Target:** 12-14
- **Key Elements:** Face death/greatest fear, supreme challenge

#### 9. Reward
- **Purpose:** Seize the sword, achieve goal
- **Chapter Target:** 14-16
- **Key Elements:** Survive ordeal, gain reward/power

### Phase 3: Return (Stages 10-12)

#### 10. The Road Back
- **Purpose:** Return to ordinary world, consequences
- **Chapter Target:** 16-18
- **Key Elements:** Chase scene, return journey begins

#### 11. Resurrection
- **Purpose:** Final test, transformation complete
- **Chapter Target:** 18-20
- **Key Elements:** Final climax, last chance for death

#### 12. Return with Elixir
- **Purpose:** Return transformed, benefit others
- **Chapter Target:** 20-24
- **Key Elements:** Return with gift/healing, world improved

## Act Breakpoints

```yaml
actBreakpoints:
  - "Call to Adventure" # Inciting incident
  - "Crossing the Threshold" # Enter special world
  - "Ordeal" # Major confrontation
  - "Resurrection" # Final test
```

## Application Guidelines

1. **Transformation:** Ensure hero changes through journey
2. **Thresholds:** Mark transitions clearly between worlds
3. **Mentor:** Can be internal or external guide
4. **Ordeal:** Make this the emotional/physical peak
5. **Elixir:** Must benefit others, not just hero

## Common Mistakes to Avoid

- Rushing through stages
- Not showing the transformation
- Making the ordeal too easy
- Forgetting the return journey
- Not having the elixil benefit others
- Skipping the refusal of the call

## Mythic Elements

- **Archetypes:** Hero, mentor, threshold guardian, shadow, trickster
- **Symbols:** Magic sword, elixir, special world markers
- **Themes:** Death and rebirth, transformation, sacrifice
- **Universal Appeal:** Cross-cultural story patterns
