# Theme Format Guide

## Standard Theme Entry Format

This reference shows the complete structure for theme entries in the living bible.

## Template

```markdown
### [Theme Name]

**Description:** [What this theme explores in the narrative]

**Progression:**
| Phase | Chapters | Description |
|-------|----------|-------------|
| 1/5 | [range] | [Introduction description] |
| 2/5 | [range] | [Development description] |
| 3/5 | [range] | [Crisis description] |
| 4/5 | [range] | [Resolution description] |
| 5/5 | [range] | [Conclusion description] |

**Phase actuelle:** [X/5] ([Phase Name])

**Porteurs du thème:**
| Personnage | Rôle thématique | Arc |
|------------|-----------------|-----|
| [Name] | [Protagoniste/Antagoniste/Miroir] | [Character's thematic journey] |

**Événements thématiques clés:**
- [Chapter/Event]: [Description of theme manifestation]
- [Chapter/Event]: [Description of theme manifestation]
- [Chapter/Event]: [Description of theme manifestation]

**Symboles associés:**
- [Symbol]: [Significance to this theme]
- [Symbol]: [Significance to this theme]

**Résonances avec autres thèmes:**
- [Other theme]: [Tension / Complémentarité / Écho] — [Brief explanation]
```

## Field Definitions

### Description
A concise statement (1-2 sentences) of what the theme explores or questions in the story.

### Progression Table
Tracks the theme's journey through all five phases:
- **Phase:** 1-5 scale
- **Chapters:** Narrative range where this phase manifests
- **Description:** What happens to the theme in this phase

### Phase Actuelle
The current phase of the theme in the story's progression.

### Porteurs du Thème (Theme Carriers)
Characters who embody, express, or are impacted by the theme:
- **Protagoniste:** Primary carrier, embodies the theme's journey
- **Antagoniste:** Opposes or complicates the theme
- **Miroir:** Reflects alternative perspective on theme
- **Catalyseur:** Triggers theme manifestations in others

### Événements Thématiques Clés
Key narrative moments where the theme is explicitly present or advanced.

### Symboles Associés
Recurring symbols, objects, or motifs that represent the theme.

### Résonances avec Autres Thèmes
Connections to other themes:
- **Tension:** Themes work at cross-purposes
- **Complémentarité:** Themes reinforce each other
- **Écho:** Themes resonate or reflect similar ideas

## Example: Complete Theme Entry

```markdown
### Confiance vs Méfiance

**Description:** L'exploration de comment la confiance se construit, se brise, et se reconstruit dans un environnement hostile.

**Progression:**
| Phase | Chapitres | Description |
|-------|-----------|-------------|
| 1/5 | 1-5 | Méfiance dominante, survie individuelle |
| 2/5 | 6-10 | Premières ouvertures, nécessité du groupe |
| 3/5 | 11-15 | Crise de confiance, trahison ou sacrifice |
| 4/5 | 16-20 | Reconstruction, nouvelle dynamique |
| 5/5 | 21-25 | Résolution, confiance gagnée ou perdue définitivement |

**Phase actuelle:** 3/5 (Crise)

**Porteurs du thème:**
| Personnage | Rôle thématique | Arc |
|------------|-----------------|-----|
| Marc | Protagoniste | Méfiance → Confiance → Test ultime |
| Julie | Miroir positif | Confiance naïve → Trahison → Méfiance guérie |
| Chen | Antagoniste thématique | Méfiance pragmatique → Confiance sélective |

**Événements thématiques clés:**
- Chapitre 3: Marc refuse l'aide de Julie (méfiance établie)
- Chapitre 8: Alliance forcée contre menace commune (première ouverture)
- Chapitre 12: Chen trahi par son ancien groupe (crise)

**Symboles associés:**
- La main tendue: Offre de confiance, souvent rejetée puis acceptée
- Le dos tourné: Vulnérabilité de la confiance

**Résonances avec autres thèmes:**
- Survie vs Humanité: Tension — la méfiance favorise la survie mais érode l'humanité
- Leadership: Complémentarité — un leader doit inspirer confiance
```

## New Theme Template

When introducing a new theme:

```markdown
### [New Theme Name]

**Description:** [What this theme explores]

**Phase initiale:** 1/5 (Introduction)

**Première manifestation:**
- Chapitre/Jour: [When it appeared]
- Comment: [How it manifested]

**Porteurs initiaux:**
| Personnage | Rôle | Raison |
|------------|------|--------|
| [Name] | [role] | [Why they carry this theme] |

**Potentiel narratif:**
- Direction probable: [How this theme might evolve]
- Conflits potentiels: [With other themes or characters]
```
