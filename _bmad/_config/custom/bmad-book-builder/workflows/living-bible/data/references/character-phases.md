# Character Psychological Phases

## Phase Scale (1-5)

This reference defines the five phases of psychological progression for characters in the living bible system.

## Phase Definitions

| Phase | Name | Description |
|-------|------|-------------|
| 1/5 | Établissement | Basic personality established, initial equilibrium |
| 2/5 | Perturbation | First doubts, questioning begins |
| 3/5 | Point de bascule | Major crisis, determining choice |
| 4/5 | Transformation | Active change, new identity forming |
| 5/5 | Nouvelle identité | Transformation complete, new equilibrium |

## Phase Progression Guidelines

### Critical Rules

- Characters must progress sequentially (no skipping phases)
- Phase progression requires clear evidence from narrative
- Not all characters reach Phase 5 — some may regress or stall
- Phase 3 is the point of no return — character is fundamentally changed

### Phase Indicators

**Phase 1/5 - Établissement:**
- Character's baseline personality established
- Core beliefs and values introduced
- Initial emotional patterns shown
- Relationship dynamics established
- Character at equilibrium with their world

**Phase 2/5 - Perturbation:**
- First cracks in established worldview
- Doubts about beliefs or values
- Emotional responses begin to shift
- Relationships tested or complicated
- Equilibrium disrupted but not yet broken

**Phase 3/5 - Point de bascule:**
- Character faces fundamental choice or crisis
- Old beliefs/worldview challenged to core
- Emotional intensity peaks
- Relationship patterns may break or transform
- **This is the turning point** — no going back

**Phase 4/5 - Transformation:**
- Character actively building new identity
- New beliefs taking hold (but not fully settled)
- Emotional patterns shifting
- Relationships in transition
- Moving toward new equilibrium

**Phase 5/5 - Nouvelle identité:**
- Transformation complete
- New beliefs fully internalized
- Emotional patterns stabilized
- New relationship dynamics established
- Character at new equilibrium

## Usage in Updates

When updating character psychological phases:

1. **Identify current phase** from existing entry
2. **Find evidence in narrative** for progression
3. **Document the trigger** — what caused the change
4. **Update to next phase ONLY** with clear evidence
5. **Note the nature** of the change (positive, negative, ambiguous)

## Special Cases

### Regression
Characters can regress phases (e.g., 4→3) BUT:
- Requires strong evidence (trauma, setback)
- Must document why regression occurred
- Regression is itself a plot development

### Stalled Characters
Characters may remain at same phase for multiple chapters:
- Document why they're stuck
- Note what would trigger progression
- This is valid character development (inertia)

### Rapid Progression
Characters progressing quickly (multiple phases in one event):
- Ensure each step is justified
- Document the intensity of the catalyst
- Extreme events can drive rapid change

## Examples

### Example 1: Standard Progression

```markdown
**Phase précédente :** 2/5 — Marc begins to trust others

**Déclencheur :** Julie saves his life at personal cost

**Phase actuelle :** 3/5 — Must choose: continue mistrusting or accept vulnerability

**Evidence :** Marc hesitates to reciprocate, showing internal conflict
```

### Example 2: Regression

```markdown
**Phase précédente :** 4/5 — Chen building new trust in group

**Déclencheur :** Group betrays Chen by abandoning him

**Phase actuelle :** 3/5 — Trust shattered, must rebuild or reject entirely

**Evidence :** Chen returns to survival-at-all-costs mentality
```

### Example 3: Stalled

```markdown
**Phase actuelle :** 3/5 — Unable to choose (multiple chapters)

**Blockage :** Fear of making wrong choice paralyzes action

**What would trigger progression :** External crisis forces decision

**Note :** Extended stay at Phase 3 shows depth of character's struggle
```

## Relationship to Character Arcs

Psychological phases track the internal journey, while character arcs track the external manifestation:

- **Arc:** "Méfiance → Confiance" (the thematic journey)
- **Phases:** Track where character is on that journey
- **Phase 3 of arc:** Character actively choosing mistrust or trust
- **Phase 5 of arc:** New relationship to trust fully established
