# Pacing Analysis Framework

## Overview

This framework defines the systematic approach to analyzing narrative pacing in chapters. It provides standardized metrics, evaluation criteria, and assessment methods for rhythm analysis.

## Pacing Types

### Action Pacing
**Characteristics:**
- High event density
- Short, punchy sentences
- Active verbs dominate
- Minimal internal monologue
- External conflict focus

**Indicators:**
- Verbs of action (run, fight, chase, grab, etc.)
- Dialogue tags with action beats
- Sensory details in motion
- Paragraph breaks frequent (1-3 sentences)

**Purpose:**
- Advance plot rapidly
- Create urgency
- Build tension
- Deliver climactic moments

### Transition Pacing
**Characteristics:**
- Movement between locations/times
- Passage of time indication
- Context shifting
- Bridge elements present

**Indicators:**
- Time markers ("Later," "The next morning")
- Location changes
- POV shifts
- Ellipsis devices

**Purpose:**
- Connect scenes
- Control narrative speed
- Provide breathing room
- Set up new contexts

### Reflection Pacing
**Characteristics:**
- Internal monologue dominant
- Longer, complex sentences
- Passive states and contemplation
- Emotional processing
- Memory and backstory integration

**Indicators:**
- Abstract nouns dominate
- Conditional statements
- Qualitative descriptors
- Paragraphs longer (5-10+ sentences)

**Purpose:**
- Character development
- Emotional resonance
- Theme exploration
- Reader processing time

## Pacing Metrics

### Event Density
**Calculation:**
```
Events per 1000 words = (Plot events / Total words) × 1000
```

**Classification:**
- High: 8+ events/1k words
- Medium: 4-7 events/1k words
- Low: 1-3 events/1k words

### Sentence Velocity
**Average Sentence Length by Pacing Type:**
- Action: 8-12 words
- Transition: 12-18 words
- Reflection: 18-25 words

**Measurement:**
```
Avg Sentence Length = Total words / Total sentences
```

### Dialogue Ratio
**Calculation:**
```
Dialogue % = (Dialogue words / Total words) × 100
```

**Optimal Ranges:**
- Action scenes: 30-50% dialogue
- Transition: 20-30% dialogue
- Reflection: 10-25% dialogue

## Pacing Distribution Analysis

### Ideal Chapter Structure
```
Opening Hook (5-10%):      Action or High Transition
Rising Action (10-60%):    Mix with acceleration toward climax
Climax/Peak (60-80%):      Sustained Action with peak tension
Falling Action (80-95%):   Transition to Reflection
Resolution (95-100%):      Reflection or calm Transition
```

### Distribution Targets
**Single Chapter:**
- Action: 50-70%
- Transition: 15-25%
- Reflection: 15-30%

**Action-Heavy Chapters:**
- Action: 70-85%
- Transition: 10-15%
- Reflection: 5-15%

**Character/Emotion Chapters:**
- Action: 30-50%
- Transition: 15-25%
- Reflection: 30-50%

## Pacing Assessment Criteria

### Score Calculation
For each scene, evaluate:
1. **Pacing Type Appropriateness** (0-2 points)
   - Does the pacing match the content?
   - Is the intensity level right for the moment?

2. **Flow Within Scene** (0-2 points)
   - Do sentence lengths vary appropriately?
   - Is the momentum consistent?
   - Are there awkward pacing shifts?

3. **Pacing Transitions** (0-2 points)
   - Do pacing changes feel natural?
   - Is the reader prepared for shifts?

4. **Reader Engagement** (0-2 points)
   - Is the reader's attention maintained?
   - Does the pacing serve the emotional experience?

5. **Technical Execution** (0-2 points)
   - Dialogue tags appropriate
   - Paragraph breaks effective
   - White space used well

**Scene Score = Sum of criteria (0-10)**

**Chapter Pacing Score = Average of all scene scores**

## Common Pacing Issues

### Rushed Pacing
**Symptoms:**
- Event density too high
- Insufficient reaction time
- Emotional beats skipped
- Reader disorientation

**Detection:**
- Action > 85% consistently
- Avg sentence length < 8 words
- Scene transitions < 50 words
- Missing reflection after major events

### Sluggish Pacing
**Symptoms:**
- Event density too low
- Excessive internal monologue
- Repetitive information
- Reader disengagement

**Detection:**
- Action < 30% consistently
- Avg sentence length > 25 words
- Paragraphs > 15 sentences
- No tension build for 1000+ words

### Uneven Pacing
**Symptoms:**
- Jarring shifts between speeds
- Inconsistent sentence velocity
- Pacing contradicts content
- Reader whiplash

**Detection:**
- Sentence length variance > 20 words within scenes
- Pacing type changes without transition
- Action scenes following reflection without bridge

## Pacing Improvement Guidelines

### To Accelerate Pacing
1. Shorten sentences (target 8-12 words)
2. Increase verb strength
3. Reduce dialogue tags
4. Break paragraphs more frequently
5. Remove unnecessary sensory details
6. Focus on external action
7. Eliminate backstory/memoir

### To Decelerate Pacing
1. Lengthen sentences (target 18-25 words)
2. Add internal monologue
3. Expand sensory descriptions
4. Include character reflections
5. Combine paragraphs
6. Add dialogue with subtext
7. Integrate backstory naturally

### To Smooth Pacing
1. Add transitional beats between pacing types
2. Gradually adjust sentence length
3. Bridge scenes with micro-transitions
4. Maintain consistent rhythm within sections
5. Prepare reader for pacing shifts

## Analysis Checklist

For each scene:
- [ ] Identify pacing type (action/transition/reflection)
- [ ] Calculate event density
- [ ] Measure average sentence length
- [ ] Determine dialogue ratio
- [ ] Assess pacing appropriateness for content
- [ ] Check for pacing consistency
- [ ] Identify pacing issues
- [ ] Note pacing transitions
- [ ] Score scene pacing (0-10)
- [ ] Document improvement suggestions
