# Severity Classification Rules

## Overview
All issues identified during review must be classified by severity to help authors prioritize fixes. Severity levels are: Critical, Major, and Minor.

---

## Character Consistency

### Critical
- Character completely breaks established personality (e.g., pacifist suddenly violent without explanation)
- Fundamental motivation contradicted without narrative justification
- Character knowledge/abilities appear without explanation

### Major
- Minor personality drift or inconsistent dialogue pattern
- Emotional reactions don't match established psychology
- Voice inconsistencies that break reader immersion

### Minor
- Minor physical description inconsistency
- Temporary character behavior inconsistency that self-corrects

---

## Location Accuracy

### Critical
- Location changes fundamental properties without explanation (e.g., small village becomes city)
- Geographical impossibility that breaks plot logic
- Location existence contradicted (appears/disappears)

### Major
- Description inconsistent or geography implausible
- Distance/travel time contradictions affecting plot
- Setting details shift without explanation

### Minor
- Minor detail inconsistency (e.g., room layout variation)
- Cosmetic description changes

---

## Object Tracking

### Critical
- Plot-critical object appears/disappears without explanation
- Weapon/tool availability contradicted during key scenes
- Object properties change fundamentally affecting plot

### Major
- Important object not tracked consistently
- Possession timeline has gaps affecting story logic
- Object location contradicted between scenes

### Minor
- Minor object inconsistency (non-plot-critical)
- Cosmetic object property changes

---

## Timeline Validation

### Critical
- Timeline contradiction that breaks story logic (e.g., event happens before its cause)
- Temporal paradox or impossible sequence
- Character in two places simultaneously without explanation

### Major
- Implausible time passage or sequence issue
- Event order confusion affecting plot comprehension
- Time reference contradictions

### Minor
- Minor timeline inconsistency (non-plot-affecting)
- Minor time reference ambiguity

---

## Plot Hole Detection

### Critical
- Plot contradiction that breaks story logic
- Unresolvable logical contradiction
- Major plot point abandoned without resolution

### Major
- Significant loose end or unresolved thread
- Character knowledge without plausible source
- Setup without payoff (or vice versa) affecting reader satisfaction

### Minor
- Minor plot inconsistency
- Small unresolved detail (non-plot-critical)
- Minor coincidental convenience

---

## Quality Issues

### Critical
- Systemic quality issue affecting multiple scenes (e.g., repetitive dialogue throughout)
- Pacing problem rendering scenes unintelligible
- Fundamental structural issue affecting readability

### Major
- Quality issue affecting one scene significantly
- Dialogue that sounds out of character
- Show-don't-tell violation affecting immersion

### Minor
- Localized quality issue
- Weak prose or awkward constructions
- Minor repetition or phrasing problem

---

## Severity Priority Order

1. **Critical** — Must fix before finalizing manuscript
2. **Major** — Should fix before publishing
3. **Minor** — Polish before final version

## Application Guidelines

- When in doubt, err on the side of higher severity
- Consider impact on reader experience and story logic
- Critical issues break story; Major issues distract; Minor issues are polish
- Always provide specific location references for all severity levels
- Always suggest actionable corrections for all severity levels
