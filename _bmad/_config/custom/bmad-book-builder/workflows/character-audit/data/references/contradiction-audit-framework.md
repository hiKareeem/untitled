# Contradiction Audit Framework

## Overview

This framework defines the methodology for systematically auditing character contradictions in individual chapters, based on AgentAdam's character psychology approach.

## Core Principles

### 1. Systematic Verification

Every contradiction in a character's profile must be checked individually against chapter content:

- **Minimum 5 contradictions** should be defined per character (AgentAdam standard)
- **Each contradiction** gets a ✅/❌/⚪ designation
- **Specific evidence** must be provided from the chapter
- **Context matters** — apparent violations may have justification

### 2. Contradiction Types

Common contradiction patterns to identify:

- **Values vs Actions**: Character claims to value X but does Y
- **Self-Image vs Reality**: How character sees themselves vs how they actually are
- **Public vs Private Persona**: Difference between public mask and private self
- **Desire vs Fear**: What character wants vs what they're afraid of
- **Words vs Actions**: What character says vs what character does
- **Emotional vs Rational Response**: Conflict between feeling and thinking

### 3. Evidence Standards

For each contradiction check, provide:

**Chapter Evidence:**
- Specific scene or moment (chapter reference)
- Dialogue or internal monologue (direct quote or paraphrase)
- Action taken by character (what they did)
- Context of the behavior (situation, stakes, pressure)

**Analysis Structure:**
```
Contradiction: [Type and description]
Chapter Behavior: [What character does/says/thinks]
Coherence Check: [Does it align, violate, or not apply?]
Conclusion: ✅ COHÉRENT / ❌ INCOHÉRENT / ⚪ NON APPLICABLE
Evidence: [Specific chapter evidence]
```

### 4. Rating System

**✅ COHÉRENT**
- Character behavior aligns with established contradiction
- Maintains psychological consistency
- Example: Character who "values honesty but lies to protect feelings" does lie in chapter

**❌ INCOHÉRENT**
- Character behavior violates established contradiction
- Breaks psychological consistency
- Requires revision or strong justification
- Example: Character who "never lies" tells unexplained lie

**⚪ NON APPLICABLE**
- Contradiction not tested in this chapter
- Character behavior doesn't relate to this contradiction
- Example: "Public vs Private persona" not tested if character alone

### 5. Scoring Formula

**Contradictions Score** = (Coherent / Total Checked) × 100

**Rating Scale:**
- 80-100%: ✅ EXCELLENTE — Strong psychological consistency
- 60-79%: ⚠️ ACCEPTABLE — Minor issues to monitor
- < 60%: ❌ PROBLÉMATIQUE — Significant inconsistencies

### 6. Common Pitfalls

**AVOID:**
- Skipping contradictions (must check ALL)
- Vague assessments without specific evidence
- Marking as incoherent without clear chapter evidence
- Not considering context before marking violations
- Forgetting that some chapters may not test all contradictions

**REMEMBER:**
- Character absence in chapter = ⚪ for all contradictions
- Minor inconsistencies may be justified by context
- Author feedback is essential for borderline cases
- Goal is constructive feedback, not criticism

1. **Deep contradiction mining** — 5+ contradictions per character
2. **Chapter-by-chapter verification** — systematic checking
3. **Evidence-based assessment** — specific examples, not generalities
4. **Psychological consistency** — maintaining truth to character complexity
