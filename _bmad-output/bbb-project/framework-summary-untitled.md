# Framework Summary: Snowflake + Psychological 5-Phase Hybrid

## Why This Framework?

This story demands two things simultaneously: structural control over 7+ parallel POV threads converging on shared catastrophic events across multiple global locations, and deep psychological transformation within each character as they discover different faces of the same systemic lie. No single framework handles both.

The Snowflake Method (Ingermanson) provides progressive macro-construction — building from premise outward through characters, plot, and scene-level detail. It was designed for exactly this scale of complexity: multi-POV, 200K+ word novels with layered worldbuilding.

The Psychological 5-Phase model (AgentAdam) provides per-character inner arc structure — five stages of transformation that ensure every POV has a complete psychological journey, not just a sequence of events they witness.

The hybrid uses Snowflake as the horizontal scaffolding (parallel threads, convergence, pacing) and 5-Phase as the vertical scaffolding (each character's inner transformation through shared events).

---

## Framework Overview

### Snowflake Method — Key Principles

1. **One-sentence summary** → one-paragraph summary → one-page synopsis → per-character synopses → expanded plot → scene list. Each pass adds a layer across all threads.
2. **Character-first expansion** — after the premise is set, each major character gets a one-page summary (motivation, goal, conflict, epiphany, arc) before plot is expanded.
3. **Progressive detail** — no section is finalized until all parallel sections are at the same level of detail. This prevents over-developing one thread while others remain skeletal.
4. **Scalable** — designed to handle any number of POVs and subplots by treating each as a parallel construction track.

### Psychological 5-Phase — Key Principles

1. **Phase 1: Equilibrium** — the character's status quo. Not necessarily happy, but stable. The world as they understand it.
2. **Phase 2: Disruption** — an event or discovery that shatters the equilibrium. Cannot be ignored or undone.
3. **Phase 3: Struggle** — the character attempts to restore equilibrium or adapt. Old tools fail. Identity is tested.
4. **Phase 4: Transformation** — the character changes fundamentally. They cannot return to who they were.
5. **Phase 5: New Equilibrium** — a new stable state, carrying the cost of transformation. Not necessarily better — often tragic.

## Framework Adaptation Notes

- **The 5-Phase "New Equilibrium" for Mirelle is non-standard.** Her transformation is absorption — her new equilibrium is *being inside the void*. This is valid within the model; the phase completes, it simply completes in a way that removes her from conventional narrative participation.
- **Snowflake's progressive method must account for the 7th POV being undefined.** Placeholder construction tracks should be maintained at each expansion pass so the Sump civilian can be slotted in at full detail once defined.
- **Revelation pacing overrides strict chronological POV rotation.** Some chapters may need to be sequenced for *information architecture* rather than temporal order — showing Sofia's data chapter before Nikolai's deployment chapter so the reader carries knowledge the characters don't.
- **The Hero's Journey was explicitly rejected** — this story resists the monomyth's return-with-the-elixir structure. Nobody comes home whole.
